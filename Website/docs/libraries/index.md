# Libraries

The common libraries, in dependency order.  Each library's design pages are written next to its code.

| Library | Is |
|---|---|
| [BaseLib](baselib/index.md) | The foundation: containers, strings, memory and its allocators, numbers, parsers and the markup tree, files, and the Codabase. |
| [StandardLib](standardlib/index.md) | The object system built on it: objects and pointers, roots, freeing, weak references, threads; and the text diff, deflate and PNG. |
| [WindowLib](windowlib/index.md) | The windowing toolkit: windows, components, layout, docking, the text area, input and its native backends. |
| [SupportLib](supportlib/index.md) | Images, drawing and fonts, sound and the MOD player, shapes, meshes and scenes, unwrapping and virtual textures. |
| [ProceduralLib](procedurallib/index.md) | Isosurfaces (marching cubes, dual contouring, octrees) and procedural textures. |
| [GerberLib](gerberlib/index.md) | Gerber and Excellon files: parsing, writing, panels, SVG and rendering. |
